# OverTheWire Bandit Wargame Solutions & Learning Journey

## Overview

This repository documents my solutions to the OverTheWire Bandit wargame (from Level 0 to Level 20). 
A hands-on series of Linux challenges designed to develop practical command-line skills and problem-solving.

## Purpose

- To systematically record my step-by-step processes and commands used to overcome each Bandit level from Level 0 to Level 20.  


## What I Learned

Through solving these challenges, I have gained practical experience in:  

- Navigating and manipulating files and directories safely
- Using essential tools: ls, cat, grep, find, file, and diff
- Handling file permissions, hidden files, and tricky filenames
- Working with compression and encoding: gzip, bzip2, tar, base64
- Establishing and managing network connections with netcat and openssl
- Understanding process control and job management
- Using SSH keys and exploring setuid binary behavior

The documentation includes terminal outputs to illustrate actual commands and responses, demonstrating my command-line fluency and diagnostic approach.


## Getting Started

To explore my solutions and learning journey:

1. Browse the markdown files organized by levels.
2. If you want, you can also clone the repo: https://github.com/muntas1rr/OverTheWire-Bandit-Level-0-to-20.git
3. Read the **Level Goal**, followed by explanations and terminal output demonstrating each solution.
4. Use this repository as a reference or learning resource for similar Linux command-line challenges.


## How to Use This Repo

- Each level is documented with:  
  - A clear **Level Goal** explaining the challenge  
  - A concise explanation of the approach and commands used to solve it  
  - Real terminal command output excerpts for verification and learning

- Files are organized sequentially by level for easy reference.
